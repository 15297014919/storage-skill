# 选型报告契约

输出可读 Markdown，并包含以下 YAML 摘要。未知值使用 `待验证`，不得省略字段。

```yaml
需求摘要:
  数据规模: ""
  读写负载: ""
  延迟目标: ""
  一致性与事务: ""
  查询模式: []
  可用性与容灾: ""
  生命周期与扩展: ""
  成本约束: ""
显式假设: []
推荐方案:
  组件: []
  置信度: 高|中|低
  能力对齐: []
推荐理由: []
次优方案:
  组件: []
  适用条件: []
明确淘汰方案:
  - 组件: ""
    原因: ""
决策轨迹:
  - 候选: ""
    硬约束: 通过|淘汰|待验证
    加权分: 0
    证据: []
    假设: []
已识别风险与反模式: []
验证建议:
  - 目标: ""
    环境: staging|只读
    指标: []
    步骤: []
    通过标准: ""
    停止条件: ""
引用来源:
  - 标题: ""
    链接: ""
    更新时间: ""
    支撑结论: ""
待验证项: []
```

## 输出检查

- 推荐、次优、淘汰三类结论齐全。
- 每个内部事实都有来源，或进入 `待验证项`。
- 每个候选保留硬约束、分数、证据和假设。
- 验证计划包含环境、指标、通过标准和停止条件。
- 不含生产写操作、未授权压测或敏感数据查询。
